# base-project-frontend

Базовый шаблон фронтенд-проекта на React + TypeScript + Vite + Redux.

## Установка и запуск

```bash
# Установка зависимостей
pnpm install

# Запуск dev-сервера (доступен по сети)
pnpm dev

# Сборка проекта
pnpm build

# Предпросмотр собранной версии
pnpm preview
```

Dev-сервер запускается с флагом `--host`, то есть доступен не только на `localhost`, но и по локальной сети.

## Скрипты

| Скрипт               | Описание                                                         |
| -------------------- | ---------------------------------------------------------------- |
| `pnpm dev`           | Запуск dev-сервера с доступом по сети                            |
| `pnpm build`         | Проверка типов (`tsc -b`) и production-сборка                    |
| `pnpm preview`       | Локальный предпросмотр production-сборки                         |
| `pnpm lint`          | Проверка ESLint (`ts`, `tsx`), без предупреждений                |
| `pnpm lint:fix`      | Автоисправление ошибок ESLint                                    |
| `pnpm format`        | Форматирование Prettier всех файлов                              |
| `pnpm format:check`  | Проверка форматирования без изменений                            |
| `pnpm stylelint`     | Проверка CSS/SCSS                                                |
| `pnpm stylelint:fix` | Автоисправление CSS/SCSS                                         |
| `pnpm prepare`       | Установка Husky (выполняется автоматически после `pnpm install`) |

## Правила разработки

- Использовать **pnpm** (не `npm` / `yarn`), чтобы lock-файл не расходился.
- Использовать Prettier-форматирование (`pnpm format`).
- Комментарии, документация и интерфейсы — на русском (или единообразно по проекту).
